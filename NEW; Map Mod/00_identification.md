# Identification

## Conclusion

**Xaero's World Map** is the overwhelmingly likely mod in the supplied screenshot.

## Visual fingerprint

The screenshot shows all of the following together:

- world-scale fullscreen map rather than a minimap;
- coordinates and biome at top center;
- cardinal compass at upper right;
- a vertical map toolbar on the right;
- zoom factor at bottom center;
- `Top Y: 97` immediately above the zoom value;
- Nether cave geometry with large areas of void/unknown black;
- bright lava contrasted against Nether terrain.

The decisive textual fingerprint is `Top Y`. Xaero's World Map documentation uses the setting name **Cave Mode Top Y** and describes both **Layered** and **Full** cave modes. The official FAQ also describes using Full cave mode in the Nether below the bedrock roof.

## Confidence

Identification confidence: **very high**.

A pixel-perfect UI comparison could be performed against a local Xaero install, but there is no serious competing map mod that matches the full combination above as closely.
