### Dragon pathfinding

The main animation keeps the flight graph and seven-state machine visible at once. Its radial RPG-style network begins fully connected and loses links as End crystals are destroyed; the central gauge reports the exact perch probability $P = 1 / (3 + n_{\mathrm{crystals}})$.

### Placement animations

Village and Nether candidate coordinates use the Java 1.16.1 candidate-stage algorithms. Their terrain fields are deterministic context layers for legibility, not claims of bit-exact biome or density generation.

### Stronghold rings

The left subplot contains all 128 seeded candidates in the source-faithful eight-ring iterator. The right subplot visualizes 1,800 independent triangulation trials with $1.2^\circ$ Gaussian bearing noise, separating generation geometry from measurement uncertainty.

               region_x * region_x * 4987142 +

               region_z * 389711 +
